05
Personal project In development

TikTokii — save places discovered through TikTok

TikTokii addresses a practical problem: restaurants, cafés, hotels and activities discovered on TikTok are often difficult to find again. The product goal is to turn a TikTok link into a verified place that can be saved to a personal collection and map.

Current implementation

The React interface supports address search and displays returned coordinates as a Leaflet marker. Users can name the selected place and send it to a Django backend designed around GeoDjango and PostgreSQL/PostGIS.

Next milestone

Build the import pipeline that extracts location signals from captions, speech and visible text, verifies a place candidate through geocoding and asks the user for confirmation when confidence is uncertain.

  • Python
  • Django
  • GeoDjango
  • React
  • Vite
  • Leaflet
  • PostgreSQL
  • PostGIS

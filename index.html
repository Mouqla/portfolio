Personal projectIn progress

TikTokii — place discovery from TikTok videos

TikTokii is a personal full-stack product designed to solve a simple problem: interesting restaurants, cafés, hotels and activities are often discovered on TikTok but become difficult to find again. The product goal is to let a user paste a TikTok URL, identify the real-world place shown or mentioned, verify its location and save it to a personal collection and map.

Current implementation

The React interface supports address search and displays the returned coordinates as a Leaflet marker. A user can name the selected place and send it to the Django backend. The backend is designed around GeoDjango and PostgreSQL/PostGIS for geographic data.

Next milestone

Build the TikTok import pipeline: extract location signals from captions, speech and visible text, identify a place candidate, verify it through geocoding and ask for user confirmation when confidence is uncertain.
